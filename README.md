## 📖 About The Project

The **LangGraph Learning Project** is a collection of Python scripts and Markdown files that demonstrate various features and concepts of the LangGraph library. Each Python script is a self-contained example, and the accompanying Markdown file provides a detailed explanation of the code and concepts.

## 🚀 Getting Started

Follow these steps to set up and run the project.

### Prerequisites

- Python 3.12

### Installation

1. **Clone the repository**

   ```sh
   git clone https://github.com/ThomasAnderson-alt/Langgraph_Learning.git
   ```

2. **Navigate to the project directory**

   ```sh
   cd Langgraph_Project
   ```

3. **Create and activate a virtual environment**

   ```sh
   python -m venv venv
   .\venv\Scripts\activate
   ```

4. **Install dependencies**

   ```sh
   pip install -r requirements.txt
   ```

## ⚙️ Usage

Each example can be run directly from the command line. For instance, to run the simple state machine example:

```sh
python Langgraph_Simple_State_Machine.py
```

Each `.py` file has a corresponding `.md` file that explains the code in detail. It is recommended to read the Markdown file before or alongside studying the Python script.

## 🏗️ System Structure

The **LangGraph Learning Project** is structured to provide clear examples of LangGraph features. Below is an overview of the system structure:

1. **State Machine Module**: Demonstrates the basic setup of a LangGraph state machine (`Langgraph_Simple_State_Machine.py`).
2. **Chatbot Module**: Implements a simple chatbot using LangGraph (`Langgraph_Chatbot.py`).
3. **Tool Integration Module**: Shows how to integrate and use tools within a LangGraph application (`Langgraph_Tool_Calling.py`).
4. **Advanced Features Module**: Includes examples for conditional looping, multi-agent collaboration, memory management, and human-in-the-loop approval (`Langgraph_Loop_Condition.py`, `Langgraph_Multianget.py`, `Langgraph_Memory.py`, `Langgraph_Approval.py`).

This modular design ensures that each feature is isolated for easy understanding and experimentation.
